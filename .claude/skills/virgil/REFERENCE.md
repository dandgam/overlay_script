# REFERENCE.md — справочник команд Virgil

> Lazy-load. Читается **только в QUESTION mode** — когда пользователь спрашивает «как сделать X», «virgil умеет Y?», «что за команда Z».
> Source of truth — `src/bmad_orchestrator/cli/main.py`. При расхождении верь коду.
> Полный путь к CLI: `/home/server/bmad-orchestrator/.venv/bin/bmad-orchestrator` (см. `templates/command-bridge.md` раздел 0).

## Как пользоваться этим файлом

Пользователь задал вопрос про возможности Virgil → найди команду в таблицах ниже → ответь простым русским языком. Если вопрос про действие которое есть в меню — подскажи путь по меню (`/virgil` → раздел → пункт). Файлы не создавать, ничего не выполнять без явной просьбы.

## Запуск и управление проходами

| Команда | Что делает | Меню |
|---|---|---|
| `run --project X --wave Y --max-parallel N` | Запустить новый проход: DAG → работники в worktrees → merge gate | 🚀 → Новый проход |
| `resume --project X --wave Y` | Продолжить прерванный проход с того же места | 🚀 → Продолжить прерванный |
| `pause` | Мягкая пауза — работники доделают текущую задачу | 🚀 → Остановить → Пауза |
| `resume` (без аргументов) | Снять паузу | 🚀 → Остановить → Продолжить |
| `stop --graceful` | Остановить после завершения текущих задач | 🚀 → Остановить → Стоп |
| `stop --hard` | Немедленно убить работников (SIGKILL) | 🚀 → Остановить → Экстренный стоп |
| `dag --wave X` | ASCII-граф зависимостей задач (без запуска) | 🚀 → Сухой прогон |
| `multi --projects a,b,c` | Очередь из нескольких проектов подряд | — (Session 3+) |

## Статус, логи, бюджет

| Команда | Что делает | Меню |
|---|---|---|
| `status` | Снимок текущего состояния всех проходов | 📊 → Что сейчас работает |
| `status --live` | То же, обновляется каждую секунду | 📊 → Что сейчас работает → Живое |
| `budget [--wave X]` | Сколько токенов/денег потрачено (по проходу или всего) | 📊 → Сколько денег потрачено |
| `logs --worker W --tail N` | Последние N строк лога работника | 📊 → Логи работника |
| `retro --wave X` | Retrospective — текстовый разбор прохода | 📊 → Подробно → Разбор |
| `memory --wave X` | Lessons learned, накопленные за проход | 📊 → Подробно → Память |

## Настройка проектов

| Команда | Что делает | Меню |
|---|---|---|
| `init <path>` | Зарегистрировать BMad-проект в реестре | ⚙️ → Проекты → Зарегистрировать |
| `scan` | Список всех проектов + статус на диске (ok/stale/missing) | ⚙️ → Проекты → Список |
| `doctor <slug>` | Health-check одного проекта | ⚙️ → Проекты → Проверить здоровье |
| `resume-project <slug>` | Подсказка как продолжить работу над проектом | — |

## Модели Claude по ролям

| Команда | Что делает | Меню |
|---|---|---|
| `model show` | Текущая модель для каждой роли | ⚙️ → Модели → Показать |
| `model set <role> <model> [--save]` | Назначить модель роли (или `all` — всем) | ⚙️ → Модели → Изменить |
| `model save` | Записать текущую раскладку в YAML | ⚙️ → Модели → Сохранить |

Роли: `planner` (строит DAG), `reviewer` (код-ревью), `dev` (разработка), `routine` (рутина), `mechanical` (механические правки), `fallback` (запасная).

## Policy (правила автоматизации)

| Команда | Что делает | Меню |
|---|---|---|
| `validate-policy [--path P]` | Проверить policy YAML на синтаксис | ⚙️ → Policy → Проверить YAML |
| `policy-apply <slug> [--auto-apply]` | Применить предложенные правки policy к проекту | ⚙️ → Policy → Применить |
| `policy-rollback <slug> <proposal_id>` | Откатить применённую правку из бэкапа | ⚙️ → Policy → Откатить |

## Skills (встроенные BMad-скиллы)

| Команда | Что делает | Меню |
|---|---|---|
| `skill-update [--source S] [--apply]` | Обновить skills/upstream/, дифф, переприменить патчи. Без `--apply` — сухой прогон | ⚙️ → Skills → Обновить |
| `skill-status` | Версия upstream + применённые патчи + конфликты | ⚙️ → Skills → Статус |

## Частые вопросы

- **«Как запустить проект?»** → `/virgil` → 🚀 Запустить → 🆕 Новый проход. Нужны: имя проекта (из `scan`), номер прохода (`1a`), число работников.
- **«Сколько потрачено?»** → `/virgil` → 📊 Статус → 💰 Сколько денег потрачено.
- **«Проход завис, как убить?»** → `/virgil` → 🚀 Запустить → ⏹ Остановить → 💥 Экстренный стоп.
- **«Чему агент научился?»** → `/virgil` → 🧪 Качество → 🧬 Самообучение → 📚 Чему научился.
- **«Проект не виден в меню»** → его надо зарегистрировать: ⚙️ Настройка → 📁 Проекты → ➕ Зарегистрировать.
