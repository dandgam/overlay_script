# Sub-меню «📊 Статус и логи»

Загружается когда пользователь выбрал «📊 Статус и логи» в главном меню. Перед вызовом CLI — прочитай `../templates/command-bridge.md`.

`AskUserQuestion`:

- **question:** «Что посмотреть?»
- **header:** «Virgil → Статус»
- **multiSelect:** false
- **options (4):**

  1. **label:** «📈 Что сейчас работает»
     **description:** «Текущий статус всех проходов: какие активны, какие работники заняты, прогресс»
     **preview:** «Можно один раз глянуть или включить живое обновление каждую секунду»

  2. **label:** «💰 Сколько денег потрачено»
     **description:** «Бюджет за конкретный проход или за всё сразу»
     **preview:** «Спрошу номер прохода (или `all` для итога по всем)»

  3. **label:** «📜 Логи работника»
     **description:** «Последние N строк лога одного конкретного работника»
     **preview:** «Спрошу имя работника (например `w-1`) и сколько строк показать»

  4. **label:** «🔍 Подробно — план, отчёт, память»
     **description:** «Углубиться в один проход: картинка зависимостей, разбор результатов, заметки»
     **preview:** «Открою подменю с 3 опциями»

## Drill-down: «📈 Что сейчас работает»

`AskUserQuestion`:
- **question:** «Как показать статус?»
- **options (2):**
  1. **label:** «📸 Один раз — снимок сейчас»
     **description:** «Покажу состояние на текущий момент и всё»
     **preview:** «Быстро. Подходит для разовой проверки»
     → `Bash` (foreground): `bmad-orchestrator status`
  2. **label:** «🎥 Живое обновление»
     **description:** «Экран обновляется каждую секунду пока не закроешь»
     **preview:** «Удобно когда хочешь следить за проходом в реальном времени»
     → `Bash` (background): `bmad-orchestrator status --live`

## Drill-down: «💰 Сколько денег потрачено»

Текстовый вопрос: «Какой wave? (формат `1a`, или `all` для всех)»

Валидация: regex `^[1-9][a-z]?$` ИЛИ строка `all`.
- Если `all` — `Bash`: `bmad-orchestrator budget` (без флага).
- Иначе — `Bash`: `bmad-orchestrator budget --wave <wave>`.

## Drill-down: «📜 Логи работника»

Два текстовых вопроса:

1. «Имя работника? (например `w-1`, `w-2`)»  — regex `^w-[0-9]+$`
2. «Сколько последних строк показать? (по умолчанию 50 — просто нажми Enter чтобы взять 50)»  — целое число ≥ 1 или пусто

Затем `Bash`: `bmad-orchestrator logs --worker <name> --tail <N>`.
