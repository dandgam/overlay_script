## Deviations from Spec (with justification)

1. **scope_from_path heuristic for absolute paths**: spec shows relative path examples. For absolute paths the heuristic returns the first meaningful path component after stripping the leading `/`. This is technically correct per "top-level dir name" but produces `home` for `/home/server/...` paths. Will refine in S4 to prefer git-root-relative paths.

2. **`_common.py` module added**: not in spec's file list, but necessary to avoid duplicating fcntl locking logic across 11 modules. This follows build discipline rule #6 (one script per family, not per situation).

3. **LLM-judge stub picks first item from pool** (not random): deterministic stub behavior makes tests reproducible. Comment in code clearly documents the stub and what the real implementation should do.

4. **`test-failures.jsonl` and `commit-history.jsonl` as additional init files**: spec listed 6 init files but §19 R3/R4 storage requires 2 more JSONL files. Both initialized empty per spec convention.
